Cookies

This website does not use cookies. There is no analytics, no advertising, no visitor tracking, and no third-party scripts. Nothing in your browser changes when you browse these pages, and no data is written to or read from your device by us.

Then why this page?

Many privacy checklists expect a cookie disclosure, so here is the honest one: there are no cookies to disclose. If we ever add a feature that stores anything in your browser, this page will be updated the same day.

Site hosting

This documentation site is served as static files from GitHub Pages. GitHub may keep standard server logs (IP address, request time) in line with its own privacy statement; we do not receive or process those logs.

The application itself

The Hyper Engine CLI and launcher never set cookies or browser state. Their network behavior is described in the Privacy page.

Hyper Engine is unofficial and not affiliated with the Friday Night Funkin’ team.
