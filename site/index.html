Run any FNF mod on the exact engine it was built for.

Hyper Engine looks at a mod folder, works out which engine it targets (Psych, Codename, FPS+, the official game…), fetches that exact engine from official sources only, and launches the mod against it — side by side with anything else you run, without touching unrelated installs.

Get Hyper Engine Read the docs

Why this exists

Friday Night Funkin' mods are built against specific engines. When a mod says “run with Psych Engine 1.0.4”, that is what it was tuned for. Hyper Engine reads the mod’s own metadata and structural markers (pack.json, meta.json + uid, metadata.json / main.xml, and so on) to pick the right engine and version instead of guessing.

Engines

Psych Engine

mods/folder with pack.json and modsList.txt (Lua + HScript).

Codename Engine

metadata.json at the mod root; content via main.xml.

FPS+ (Psych Plus)

meta.json carrying a unique uid and Haxe scripts.

Funkin’ Official

manifest.json and HaxeWeek chart data.

Every engine definition lives in the repository as reviewable TOML — with the official source URL, asset naming, and mod layout used for detection.

Only official sources

Policy. Hyper Engine downloads engines and add-ons from the creators’ own GitHub Releases and the classic FNF sources. There is no CDN, no “optimized” repack, and no download through us. HTTP is refused — only HTTPS. Shell links are gated and require consent.

Safety & openness

  • Apache-2.0 licensed, no game assets shipped (nothing copyrighted from FNF).
  • Checksums verified on download; archives are zip-slip guarded.
  • Engines install side-by-side by version; you stay in control.
  • SaraHUD is optional and opt-in (official release, first in mod order).

How it looks

A small command line (hfe) for scripts and power users, plus an optional lightweight desktop launcher built with Tauri 2. Both share the same local store, so switching between them is seamless.
