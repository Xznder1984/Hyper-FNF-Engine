Privacy

Last updated 2026-10-08. The short version first: there is no telemetry and no account.

What we do not do

  • No analytics, no tracking, no fingerprinting, no ads.
  • No account system, no registration, no user profile.
  • No phone-home in the app, launcher, or the optional SaraHUD note.
  • No uploads of your mods, files, or folder listings anywhere.

What happens on your machine

Hyper Engine reads the mod folder you point it at, only to detect the engine. Everything is computed locally. Preference data (which engine you chose for a mod, game assets path, SaraHUD preference) is stored in a local settings file next to the application data, and can be deleted at any time.

Network connections

EndpointPurpose
github.com (API + Releases)List and download official engine releases and Hyper Engine updates. HTTPS only.
Official engine/update sourcesDownloading an engine or a SaraHUD release you approved.

When you check for engine releases or updates, GitHub sees a normal API request from your IP address. If you provide a GitHub personal access token (optional, to raise the API rate limit), it is stored only in your operating system’s keyring — never in a file, never sent to us — and it is sent only to GitHub as an authentication header.

Remote configuration

Remote update manifests are verified against pinned SHA-256 digests before any auto-update. A compromised manifest cannot push arbitrary code.

Data deletion

Delete the application data directory (the CLI will tell you its exact path with hfe doctor). Because nothing is stored with us, there is nothing further to erase.

Contact

Open an issue on the GitHub repository. This project is maintained by volunteers; we do not sell or share personal data because we never receive any.

Hyper Engine is unofficial and not affiliated with the Friday Night Funkin’ team.
