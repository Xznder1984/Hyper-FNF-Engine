Download

The first public release is still being prepared. Binaries will be published under the Releases tab of the GitHub repository with a sha256.txt checksum file for every artifact. Until then, everything below is how you run the current development build.

Build from source

You need Rust (stable, ≥ 1.77.2) and, to run the desktop launcher, a system with the Tauri prerequisites.

git clone https://github.com/Xznder1984/Hyper-FNF-Engine.git
cd Hyper-FNF-Engine
cargo build --release -p hfe-cli
./target/release/hfe --help

Desktop launcher

The hyper-launcher GUI (Tauri 2) ships with the same store as the CLI. Build it locally with: 

cargo build -p hyper-launcher
cargo run -p hyper-launcher

Windows uses the preinstalled WebView2 runtime (Windows 10/11). macOS and Linux need the standard Tauri system packages (webkit2gtk, etc.).

Verify downloads

Every release upload includes sha256.txt. Verify a download on Linux/macOS with sha256sum -c sha256.txt and on Windows with Get-FileHash artifact -Algorithm SHA256.
