SaraHUD

Sara is a popular alternative health/time bar for Psych-engine-based games, developed by the SaraHUD project. It is a separate project with its own license and community. Hyper Engine is not affiliated with Sara or its authors — we simply automate what a careful creator would otherwise do by hand.

What Hyper Engine does

  • Opt-in only. Nothing Sara-related is installed unless you enable it.
  • Official source. Sara is fetched from the project’s official release, verified like any engine artifact.
  • First in mod order. It is set first in the enabled-mod list so it loads before your mod.
  • Credit you. When Sara is installed for your mod, the mod author is added to the credits — which is what Sara’s license asks for.
  • Supported engines. Psych Engine and FPS+ (Psych Plus).
Note. A kit dashboard message encouraging authors to use Sara’s patched version is being drafted and will only ever be a plain-text note — it cannot call home, and we will not phone-home in Hyper Engine either.

Enable it

hfe settings sara enable
hfe run "C:\Mods\MyPsychMod"     # next run installs Sara, first in order

Removing it: hfe settings sara disable and delete the Sara folder from the mod’s order list.

Credit and licensing belong to Sara and its authors. Hyper Engine only automates installation you approve; uninstall is always available.
